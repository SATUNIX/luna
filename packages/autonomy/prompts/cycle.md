That covers a failing check, work carried over in the handoff, a bug, a security gap, untested behaviour, docs that don't match the code, or code that needs cleaning up (dead code, duplication, needless complexity, shown with evidence). Follow the work precedence.
- **Improve mode** {{IMPROVE_MODE}} more capable, faster, more reliable or easier to use: extend what it can do, remove a limitation the docs admit to, speed up a path you have measured, or smooth a workflow users hit.
