The pi agent system · public beta

Luna

An opinionated distribution of the pi coding agent. A permission gate for tool calls, governed delegation to sub-agents, verification, durable memory and bounded recovery, chosen together as profiles. One pi package, installed once.

01 · Install

Install once.

Needs Node.js 22.19 or newer, git and pi 0.85.1 or newer.

  1. Install pi

    $ npm install -g @earendil-works/pi-coding-agent

  2. Install Luna from the release tag

    $ pi install git:github.com/SATUNIX/luna@{{TAG}}

  3. Start pi

    $ pi
# first start: the balanced profile is applied; /reload when asked
# no models listed? sign in with /login

The repository is public, so no credentials are involved. Other channels, the scripted installer, uninstalling and troubleshooting are in Installation and Getting started.

02 · How it works

Gated, bounded, verified.

Three rules hold in every profile that loads them.

Tool firewall

Every tool call meets the gate.

The firewall parses each call into its effects and tiers it: routine work is allowed, riskier calls ask you, critical ones are denied, and every decision goes to the audit record. See the autonomy gate.

Delegation guard

Delegation stays bounded.

A lead agent hands sub-agents a bounded question and integrates what comes back. The delegation guard decides what each child loads, reserves its budget before it starts, and checks inside the child that its protections loaded. Repeated multi-step work runs as a workflow, where code rather than the model decides the next step. See agent orchestration.

Verify gate

Nothing counts as done unverified.

/verify and the agent's verify_completion tool run the project's check command and an isolated, read-only reviewer against the definition of done, and record the verdict. A review that did not run never reads as a pass. See concepts.

03 · Profiles

One package, seven shapes.

A profile chooses which extensions, skills and prompts load, and the firewall mode. Switch with /profile.

ProfileFor
quickFast edits with the safety guards and checkpoints, no ceremony.
balancedEveryday work with verification and context helpers (the default).
long-horizonMulti-hour work: goals, task graph, branches, delegation.
autonomousLong-running sessions, including unattended runs in a container.
self-improvingResearch use: adds memory services, dual review and skill mining (experimental).
pentestAuthorised security engagements: strict firewall policy, scope and rules of engagement.
liteSmall local models and short contexts.

What each profile loads is generated in the capability matrix.
