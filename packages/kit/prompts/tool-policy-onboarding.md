# Tool Policy Onboarding

Classify MCP tools before use.

Tools: ${@:-the MCP tools not yet classified}

Return:

- Server name
- Tool name
- Description treated as untrusted
- Exact capability
- Risk class
- Default decision
- Approval class
- Example policy entry
- Validation or evidence expected

Do not approve or invoke the tool.
